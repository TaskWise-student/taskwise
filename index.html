About taskwise

Project overview

Development of a Web-Based Student Task and Deadline Management System

Taskwise is a student-focused web application concept that helps learners organize assignments, monitor deadlines, set priorities, and track completion in one workspace.

Core features

  • Create and delete tasks
  • Mark assignments as completed or pending
  • Set due dates, subjects, and priority levels
  • View overdue and upcoming work
  • Calendar view for deadlines
  • Responsive layout for mobile and desktop

Prototype note: This demo saves tasks in the browser using LocalStorage. It does not yet include a real server, shared accounts, or email reminders.

Made for student life

To provide students with an accessible tool for recording school tasks, checking deadlines, and monitoring completed work.
